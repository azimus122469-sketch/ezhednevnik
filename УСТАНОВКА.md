# Ежедневник: установка на свой Supabase

Приложение состоит из статичных файлов (открываются в браузере, ставятся как приложение на телефон) и базы Supabase, где хранятся записи. Ваши данные лежат только в вашем проекте.

Время установки: около 20 минут. Программировать не нужно.

## Что понадобится
- Бесплатный аккаунт на supabase.com
- Любой статичный хостинг: Vercel, Netlify, Cloudflare Pages или GitHub Pages (бесплатно)
- По желанию, для ИИ-помощника: ключ OpenAI (платный, оплата по использованию)

## Шаг 1. База
1. На supabase.com создайте новый проект (Project). Запомните пароль базы.
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла `supabase/schema.sql` и нажмите **Run**. Должно закончиться без красных ошибок. Скрипт можно запускать повторно.
3. Откройте **Project Settings → API** и скопируйте:
   - Project URL (вида `https://xxxx.supabase.co`)
   - Publishable key (он же anon key)

   Секретный ключ `service_role` никому не показывайте и в приложение не вставляйте.

## Шаг 2. Настройки входа
В **Authentication** рекомендуется:
- Если приложение только для вас: в **Sign In / Providers** отключите «Allow new users to sign up» после того, как создадите свой аккаунт (в **Users → Add user**).
- Включите защиту от утёкших паролей (Leaked password protection): доступность зависит от тарифа Supabase.
- Если регистрация остаётся открытой, включите подтверждение почты (Confirm email).

## Шаг 3. Файл настроек
1. Скопируйте `config.example.js` в `config.js`.
2. Впишите адрес проекта и публичный ключ из шага 1.

Если `config.js` не заполнен, приложение при открытии скажет об этом.

## Шаг 4. Публикация
Загрузите на хостинг файлы: `index.html`, `config.js`, `sw.js`, `manifest.webmanifest` и четыре иконки `.png`. Папка `supabase` на сайте не нужна.
Откройте адрес сайта, зарегистрируйтесь или войдите. На телефоне выберите «Добавить на главный экран».

## Шаг 5. Курс валют ЦБ (по желанию)
Приложение подтягивает официальный курс доллара ЦБ Узбекистана через функцию `cbu-rate`. Без неё курс вводится вручную (Ещё → Курс → вручную).

Развернуть (нужен Supabase CLI, [документация](https://supabase.com/docs/guides/functions)):
```bash
supabase login
supabase link --project-ref ВАШ_PROJECT_REF
supabase functions deploy cbu-rate --no-verify-jwt
```

## Шаг 6. ИИ-помощник (по желанию)
Помощник отвечает в чате и предлагает записи, но любое изменение вносится только после вашего нажатия «Одобрить».

```bash
supabase functions deploy ezh-mcp --no-verify-jwt
supabase secrets set OPENAI_API_KEY=ваш_ключ
supabase secrets set OWNER_NAME=Ваше_имя
supabase secrets set TZ_OFFSET_HOURS=5
```
- `OWNER_NAME`: как помощник к вам обращается (необязательно).
- `TZ_OFFSET_HOURS`: ваш часовой пояс относительно UTC (по умолчанию 5).
- Расход ограничивается дневным лимитом на вкладке «ИИ». Следите за балансом в кабинете OpenAI.
- Имена моделей по умолчанию заданы в коде. Если у вашего ключа таких моделей нет, задайте свои секретами `OPENAI_MODEL_LUNA` и `OPENAI_MODEL_TERRA`.

## Обновление
Заменяйте файлы на хостинге новыми. В `sw.js` номер версии кэша (`ezh-shell-vNN`) меняется при каждом выпуске, поэтому приложение у вас обновится само. Файл `config.js` при обновлении сохраняйте свой. Если выходит новая версия `schema.sql`, запускайте её повторно, существующие данные она не удаляет.

## Если что-то не работает
| Симптом | Что проверить |
|---|---|
| «Приложение не настроено» | Заполнен ли `config.js` и лежит ли он рядом с `index.html` |
| Вход не проходит | В Supabase включены ли Email-вход и подтверждение почты |
| «Нет связи», данные не грузятся | Запущен ли `schema.sql` без ошибок; верный ли ключ |
| Курс не подтягивается | Развёрнута ли функция `cbu-rate`; иначе введите курс вручную |
| ИИ пишет «не настроен» | Задан ли секрет `OPENAI_API_KEY` и развёрнута ли функция `ezh-mcp` |
